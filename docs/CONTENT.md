# 题库内容说明

## 来源与范围

内容依据人民教育出版社《普通高中教科书·物理》（2019 版）的组织方式整理：

- 必修第一册：运动的描述、匀变速直线运动、相互作用、运动和力的关系；
- 必修第二册：抛体运动、圆周运动、万有引力与宇宙航行、机械能守恒定律；
- 必修第三册：静电场、恒定电流、磁场、电磁感应、交变电流；
- 选择性必修第一册：动量守恒定律、机械振动、机械波、光；
- 选择性必修第二册：安培力与洛伦兹力、电磁感应、交变电流；
- 选择性必修第三册：分子动理论、气体、热力学定律、原子结构、原子核、波粒二象性。

题库按六个 App 模块组织：力学、振动与波、热学、电磁学、光学、近代物理。每个公式都记录章节、标准形式、适用条件、物理量及单位、常见错误、关联公式。

> 本 App 是复习工具，不是教材替代品。遇到教材版本差异或表述争议，以所用教材和教师讲解为准。

## 题目设计

每个公式恰好配置五种题型：

1. **完整公式**：从同模块相近公式中选出标准形式；
2. **公式填空**：隐藏系数、物理量、运算符或函数，要求补全；
3. **公式变形**：给定目标物理量，选择正确代数变形；
4. **适用条件**：选择成立条件、符号约定或使用限制；
5. **易混辨析**：给出真实物理情境，选择应使用的公式。

干扰项来自同模块真实公式或常见系数、符号、正反比错误，不生成“1 + 1 = 3”式的荒谬选项。每道题有独立解析，题目、选项、答案分表保存。

答案数据不在 UI 代码中硬编码：`questions.json` 只描述题目、选项和答案下标，导入时由 `SeedLoader` 校验后写入 Room 的 `questions`、`question_options`、`question_answers` 表。

## 维护流程

```bash
# 修改 tools/data_*.py 后重新生成并校验
python tools/generate_seed.py

# 验证所有公式和选项能被 Compose 公式解析器解析
./gradlew :app:testDebugUnitTest --tests "*FormulaParserTest"
```

生成器会检查：

- 公式 ID 唯一；
- 引用公式存在；
- 公式、条件、物理量、单位、解析非空；
- 每个公式具备五类能力题目（内置题库严格模式）；
- 每题恰好 4 个选项、答案下标合法、选项不重复；
- 填空包含 `\boxed{?}`；
- 关联公式有效。

## 数据边界

- 只收录“基本公式”和高考常见关系，不把每个中间推导式都独立建卡；例如 `F = qE` 作为电场强度定义式的变形在题目中考查，不再重复建立一张公式卡。
- 公式符号采用高中教材常见写法（如 `F_合`、`W_损`），不同教材版本的符号差异以章节说明为准。
- 物理量单位采用国际单位制；个别公式在题目中允许使用一致的单位制（如压强用 Pa、体积用 m³）。
- `g` 取当地重力加速度，题库中的情境不强行指定 9.8 或 10 m/s²；涉及具体数值的题目会在题干中说明。
